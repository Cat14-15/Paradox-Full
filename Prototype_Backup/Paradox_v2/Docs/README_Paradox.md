# PARADOX — 언어 장벽 4인 협동 탈출 게임

부산소프트웨어마이스터고 · UNESCO 청소년 프로젝트. Unity 6000.5 · URP 2D · Netcode for GameObjects 2.13.

## 실행 방법

1. Unity에서 `Assets/Scenes/Paradox.unity`를 열고 Play.
2. 타이틀 화면
   - **방 만들기 (호스트)**: 같은 Wi-Fi의 친구들이 로비에 표시된 IP로 참가 (포트 7777).
   - **참가하기**: 호스트 IP 입력 → 참가.
   - **혼자 테스트**: 봇 3명이 자리를 채움. `1~4` 키(또는 오른쪽 아래 버튼)로 네 역할을 번갈아 조종.
3. 로비(4인 매칭) → 캐릭터 선택 + 이름 → 프롤로그 → Stage 1~4 → 엔딩 → 결과.

같은 PC에서 온라인을 테스트하려면 빌드(File > Build)를 하나 더 띄워 `127.0.0.1`로 참가하면 된다.

## 역할 고정 · ??? 규칙

슬롯 번호 = 역할 번호. 0 조작자(한국인) · 1 통역(필리핀인) · 2 내비게이터(베트남인) · 3 관측자(남아공인).
스테이지의 현지인만 표지판을 읽고(`StageDefs.CanRead`), 나머지에게는 지글거리는 `???`로 보인다.

| 스테이지 | 현지인 | 메커니즘 | 제한시간 |
| --- | --- | --- | --- |
| 1 필리핀 · 태풍/정전 | 통역 | 릴레이 체인(통역→내비→조작자 글자 카드, 글자는 1.3초씩 날아감), 글자가 전달 중일 때만 정전 파동에 소실 → 관측자 ⚠ 타이밍, 글자 2개가 모이면 레버 선택+확정, 전원 연타, 로비 4원 동시 도착 | 없음 |
| 2 베트남 · 터널 침수 | 내비게이터 | 펌프 모드 글자 전달, 콘솔 붙잡기(방벽 사수)+물살 회피, 수문 2개 1.5초 동시 당기기, 침수 갈래 피해서 상부 통로 | 170초 |
| 3 국적 미정 · 유독가스 | 관측자 | 색상 고글 / 구조 미니맵 / 감지기 수치 → 공용 보드 교차검증, 유일한 안전 구역에서 확인 패널 2개 + 4원 | 200초 |
| 4 한국 · 지하 화재 | 조작자 | 채팅 금지·버튼 5개+글자 카드만. 방송 암호 전달, 방향 신호로 장치 3개 안내, 불 ⚠ 경고, 키패드 4초 동시 입력, 셔터 | 240초 |

Stage 3의 통역은 기획서 플로우의 "위험 경고문 해독 → 위험 구간 필터"를 **언어와 무관한 감지기 수치(ppm ≥ 50 → ✗ 표시)**로 구현했다. (Stage 3 국적/재난이 미정이라 색·구조·수치의 3중 교차검증으로 구체화)

## 아키텍처

- 서버(호스트) 권한 규칙: `Assets/Scripts/Game/GameLogic.cs` + `Stage*Logic.cs`. 상태(`SessionState`)는 JSON으로 통째로 브로드캐스트, 연속값(클록·미터)은 `NetworkVariable`.
- 네트워크 골격: `Assets/Scripts/Net/NetHub.cs`(NetworkManager·트랜스포트·런타임 프리팹), `SessionNet.cs`(상태/명령/이벤트 RPC), `AvatarNet.cs`(소유자 이동, 봇 두뇌).
- 클라이언트: `Assets/Scripts/Client/` — `Session`(내가 아는 상태), `ScreenManager`(흐름별 화면), 화면들, `StageWorld`(월드 렌더), `StageTools`(역할별 도구 패널).
- 맵은 시드로 결정적으로 생성(`StageMaps.cs`) — 서버·클라이언트가 같은 지형을 만든다. 프리팹/씬 배선 없이 전부 코드로 생성.
- 봇: 호스트가 소유. 리더(조종 중인 아바타)를 따라다니고, 도착 단계에서는 자기 원으로, Stage 2에서는 자기 장치 앞으로 간다. Stage 1 연타는 자동.

## 글자 카드 보내기

현지인은 왼쪽 글자 카드에서 글자를 순서대로 골라(트레이) **[○○에게 보내기 ▶]**를 눌러야 전송된다. 글자는 한 장씩 시간차를 두고 날아가며,
발신자 패널에 "날아가는 중 → 내비게이터 대기 중 → 조작자 도착 ✓"처럼 상태가 표시된다. Stage 1에서는 내비게이터가 [그대로 전달]을 눌러야 조작자에게 넘어간다.

## 봇 (혼자/부분 테스트)

빈 자리를 채운 봇은 실제 사람처럼 자기 역할을 수행한다(`BotDriver`: 글자 전송·중계·⚠ 경고·레버·콘솔·수문 당기기·보드 표시·확인 패널·장치·키패드, `BotBrain`: 길찾기 이동).
그래서 혼자 시작해도 실제 4인 플레이와 같은 흐름이 굴러간다. 호스트가 1~4 키로 봇 자리를 직접 조종하면 그 봇의 자동 행동은 멈춘다.

## 스테이지 화면 구성

- 왼쪽 위: 역할 카드(역할 색 띠) + "지금 할 일". 그 아래 역할별 도구 패널(글자 카드 / 릴레이 상자 / 레버 / 경고등 / 콘솔 / 물살 / 공용 보드 / 감지기 / 키패드).
- 가운데 위: 스테이지 제목·상태·타이머. 스테이지 시작 5초 동안은 "당신은 ○○ (현지인 여부)" 안내로 바뀌고, 신호 차단 중에는 차단 배너가 된다.
- 오른쪽 위: 신호 피드(내 입장에서 보이는 것), 호스트가 봇을 조종할 때는 조종 전환 버튼.
- 아래 가운데: 5버튼 신호(GO/STOP/✓/?/⚠) + 안내 역할의 방향 패드 + 조작자 채팅(Stage 1~3). 알림(토스트)은 그 바로 위에 쌓인다.
- 오른쪽 아래: 미니맵(내비게이터, Stage 4는 조작자).
- 월드: 캐릭터 머리 위에 역할 배지(역할 색)와 이름, 발밑에 역할 색 링. 표지판은 현지인만 읽히고 나머지에게는 지글거리는 ???.

## 캐릭터 그림 (역할 전용 픽셀 캐릭터)

- 조작자(한국인)와 내비게이터(베트남인)는 직접 그린 픽셀 캐릭터를 쓴다: `Assets/Art/Characters/korean.png`, `vietnam.png`.
  - 시트 규격: 160x256, 한 칸 32x64, 5칸(걷기 프레임) x 4줄(앞·뒤·왼쪽·오른쪽). 발이 칸 아래에서 7px 위에 오게 그린다.
  - 씬의 `GameApp.roleSheets[슬롯]`에 시트를 넣으면 그 역할은 캐릭터 선택 없이 전용 캐릭터로 고정된다(선택 화면에는 "전용 캐릭터"로 표시, 이름만 입력).
  - 런타임 슬라이스는 `PixelSprites`(PPU 32, 발 기준 피벗), 월드 아바타는 `AvatarView` 픽셀 모드(방향별 4프레임 걷기), UI 초상은 `UIPortrait.MakeForSlot`.
- 통역(필리핀인)·관측자(남아공인)는 아직 Jovial 종이인형 캐릭터를 고른다. 같은 규격의 `.pixil`을 주면 `roleSheets[1]`, `[3]`에 넣어 바로 교체할 수 있다.
- `.pixil` → 시트 변환: 레이어 `src`(base64 PNG)를 합쳐 프레임을 배치한다(스크래치 스크립트로 처리, 프로젝트에는 결과 PNG만 둔다).

## 테스트

`Assets/Tests/PlayMode/FullFlowTests.cs` — 혼자 테스트 모드로 타이틀부터 결과까지 전 흐름을 자동 실행한다.
`Assets/Tests/PlayMode/ScreenshotTour.cs` — 환경변수 `PARADOX_SHOTS`에 폴더를 주면 각 단계·역할별 화면을 PNG로 저장한다(화면 검수용, `-nographics` 없이 실행).
Unity 메뉴 `Window > General > Test Runner > PlayMode > Run All`, 또는 명령줄:

```
Unity.exe -batchmode -projectPath <프로젝트> -runTests -testPlatform PlayMode -testResults results.xml
```

에디터로 프로젝트를 열어 둔 상태에서는 같은 폴더로 배치 실행이 안 되므로, `Assets/Packages/ProjectSettings`만 다른 폴더에 복사해 거기서 돌리면 된다.
