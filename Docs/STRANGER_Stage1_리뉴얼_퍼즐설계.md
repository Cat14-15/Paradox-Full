# STRANGER Stage 1 리뉴얼 — 퍼즐 설계 (씬 4 이후)

> 2026-11-05 사용자와 합의한 방향. 기존 규칙(관문 1·2, 침수 현황판 등)을 대체한다.
> 취지: **협동이 "필수"** — 정답을 네 조각으로 쪼개 역할마다 한 조각씩, 소통 수단은 신호뿐. 퍼즐 하나는 1~2분, 규칙은 한 줄.

## 0. 공통 규칙
- **4역할 고정**: 조작자(이동·손전등·실제 조작) / 통역(현지어 표지판 읽기) / 내비게이터(지도·구조도) / 관측자(색·타이밍·숨은 것).
- **정보는 역할마다 다르게 보인다.** 한 명이 풀고 셋이 기다리는 구조는 만들지 않는다 — 퍼즐마다 네 명 모두 지금 할 일이 있어야 한다.
- **소통은 신호(도넛)와 핑뿐.** 신호: 예/아니오, 지금/기다려, 위·아래·왼·오, 위험, 숫자 1~4, 색 4개, 도움. 조작자 채팅은 통역만 읽을 수 있다.
- **시간 압박**: 침수까지 남은 시간. 오답은 시간 감소 또는 구간 처음으로.
- **현지어**: 표지판은 필리핀어(통역만 읽음). 퍼즐 안에서 통역의 정보가 항상 한 조각을 차지한다.
- 퍼즐이 끝날 때마다 **방 이름·역할이 달라 보이게**: 퍼즐 1~4의 "주인공 역할"을 돌려 지루함을 막는다(그래도 모두가 동시에 일한다).

## 1. 진행 순서와 장소

| # | 퍼즐 | 장소(방 이름은 StageMaps 확인 후 확정) | 목표 |
|---|---|---|---|
| 1 | 퓨즈 복구 | 안내실(퓨즈함) — 구현 완료(솔로: Tab으로 역할 전환, 온라인 동기화는 미구현) | 전원 복구 → 문 잠금 해제 · 비상등 |
| 2 | 어두운 전시실: 젖은 바닥 건너기 | 전시실(갤러리) | 출구 쪽 통로 확보 |
| 3 | 유물 보관실 암호 | 보관실 | 셔터 열쇠(코드) 획득 |
| 4 | 물길 돌리기 | 관리실 | 침수 저지(물을 배수구로) |
| 5 | 4인 동시 입력 (최종) | 메인 홀(출구) | 셔터 개방 → CLEAR |

- 일정이 빠듯하면 **3번을 뺀다**(4개로). 그때 3번의 "코드" 조각은 2번 결과로 대체.
- 각 퍼즐 결과 한 조각이 5번의 힌트가 되도록 잇는다(아이디어): 1→색, 2→방향, 3→숫자, 4→시간.

## 2. 퍼즐 상세

### 퍼즐 1 — 퓨즈 복구 (튜토리얼, 난이도 ★)
퓨즈함에 퓨즈 4개(빨·파·노·초)를 슬롯 1~4(왼→오)에 꽂는다. 정답은 **네 개의 힌트를 합치면 하나로 정해진다.**

| 역할 | 보는 것 | 내는 정보 예 |
|---|---|---|
| 통역 | 필리핀어 설명서 | "빨강은 파랑보다 왼쪽" (순서 규칙) |
| 관측자 | 함 속 퓨즈의 색 | "초록은 타서 검다 → 2번 슬롯은 안 쓴다" (제외 조건) |
| 내비게이터 | 배선도 | "노랑 퓨즈는 오른쪽 끝 슬롯에만 연결" (위치 규칙) |
| 조작자 | 퓨즈·슬롯(손) | 위 세 정보를 모아 실제로 꽂는다 |

- 힌트는 **조작자에게 직접 안 보인다.** 통역·관측자·내비게이터가 신호로 전달.
- 오답: 불꽃(감전 연출) + 시간 −15초. 정답 시: 전원 복구 효과음 + 불이 들어옴.
- 서버 검증: 슬롯 배치 배열이 정답과 같으면 성공(조각별 힌트는 정답에서 자동 생성).

### 퍼즐 2 — 어두운 전시실: 젖은 바닥 건너기 (★★★, 실시간)
지하에서 물이 올라와 바닥이 젖고, 끊어진 전선이 스파크를 튄다. 쓰러진 진열장이 일부 통로를 막고 있다.

| 역할 | 보는 것 | 내는 정보 |
|---|---|---|
| 관측자 | 스파크가 켜지고 꺼지는 리듬 | "지금 건너 / 기다려" |
| 통역 | 바닥·벽 경고판 | "이 통로는 출입금지(막힘)", "젖은 바닥 — 감전" |
| 내비게이터 | 전시실 안내도 | 막히지 않은 통로를 이어 출구까지 경로 |
| 조작자 | 손전등 반경만 | 신호를 모아 실제 이동 |

- **구현됨(패널 방식, 솔로 Tab 테스트)**: 회화 전시실의 끊어진 전선에서 [E]. 구간마다 통로 3개 — 내비게이터 안내도는 이어진 2개, 통역 안내문은 막힌 1개 → 교집합이 정답. 관측자 신호등(4초 주기, 2초 안전)이 꺼진 동안만 건널 수 있고, 감전되면 한 구간 뒤로. 온라인 동기화는 미구현.
- 어려움 포인트: **길 선택(통역+내비)** 과 **타이밍(관측자)** 이 동시에 필요. 감전 시 구간 처음으로.
- 구간 3개(통로 갈림 3회)가 기본.

### 퍼즐 3 — 유물 보관실 암호 (★★, 조용한 머리 쓰기)
보관실에 유물 4개와 받침대 4개. **오래된 순서대로** 받침대에 올리면 열쇠 보관함이 열린다. 조작자는 **한 번에 하나만** 들 수 있다.

| 역할 | 보는 것 | 내는 정보 |
|---|---|---|
| 통역 | 유물 이름표(필리핀어) | 각 유물의 시대("가장 오래됨/…") |
| 관측자 | 자외선등 아래 색·모양 | 유물 ↔ 이름표 매칭(색 4개) |
| 내비게이터 | 보관실 선반·받침대 위치도 | 어느 유물이 어느 선반, 받침대 번호 |
| 조작자 | 들기/놓기 | 신호대로 옮김(1개씩 → 이동 횟수 압박) |

- 오답: 받침대에서 유물이 튕겨 나옴 + 시간 −10초.
- **구현됨(패널 방식, 솔로 Tab 테스트)**: 수장고 벽의 유물 전시대에서 [E]. 선반 5칸(그중 1개는 복제품, 진짜 하나와 같은 이름표) + 받침대 4개. 통역=필리핀어 시대 이름(Sinauna/Kastila/Amerikano/Makabago)↔순서, 관측자=자외선에서 빛나는 복제품 칸, 내비게이터=받침대마다 올릴 순서(왼→오 정렬이 아님), 조작자=한 번에 하나씩 들어 올림. 오답이면 전부 튕겨 나오고 2초간 멈춤. 최종 퍼즐(5)은 이 퍼즐까지 마쳐야 열림. 온라인 동기화는 미구현.

### 퍼즐 4 — 물길 돌리기 (★★★, 실시간 침수)
물이 방으로 들어오고 있다. 밸브 4개를 돌려 물을 배수구로 보낸다. 밸브는 서로 연결돼 있다(하나를 돌리면 다른 하나가 같이 움직임).

| 역할 | 보는 것 | 내는 정보 |
|---|---|---|
| 내비게이터 | 위에서 본 파이프 지도 | 물이 흐르는 경로, 어느 밸브를 어느 방향으로 |
| 통역 | 밸브 이름표(필리핀어) | 밸브 이름 ↔ 번호 |
| 관측자 | 어디서 물이 새는지·색 | 현재 열린/닫힌 상태 확인 |
| 조작자 | 직접 밸브 돌림 | 신호를 모아 순서대로 |

- **구현됨(패널 방식, 솔로 Tab 테스트)**: 학예실 벽의 배수 밸브 패널에서 [E]. 밸브 4개는 서로 연동(하나 돌리면 짝도 같이). 내비게이터=열려야 할 번호, 통역=필리핀어 서수(Una/Ikalawa/Ikatlo/Ikaapat)↔번호, 관측자=연동 관계, 조작자=이름표 달린 밸브를 직접 돌림. 수위는 시간·밸브 조작·오답마다 올라가고 가득 차면 밸브가 초기화. 온라인 동기화는 미구현.
- 수위가 실시간으로 올라가며 잘못 돌리면 수위가 한 칸 더 오른다. 수위 최대 → 실패.

### 퍼즐 5 — 4인 동시 입력 (최종, 메인 홀, ★★★★)
메인 홀 바닥의 원 4개(타이틀 화면의 그 원)가 천천히 돈다. 각자 **자기 원의 불빛 패턴**만 보인다 — 4명의 패턴을 이어야 순서가 완성된다.
1. 라운드 1~3: 패턴 일부가 각자 화면에 번쩍인다. 신호로 합쳐서 **순서**를 만든다.
2. 마지막: **네 명이 동시에** 같은 박자로 자기 원에 올라선다(4/4). 한 명이라도 늦으면 처음부터.
   - **구현됨(패널 방식, 솔로 Tab 테스트)**: 중앙 홀 바닥의 원에서 [E](퍼즐 1·2·4 완료 후). 라운드마다 4박+쉼 1박, 각자 화면엔 자기 원이 켜지는 박만 보임 → 조작자가 켜진 순서대로 원 입력(1~4). 마지막은 카운트(하나~넷) 뒤 "지금!" ±0.35초 안에 네 명 모두 자기 원 입력(솔로: 키 1~4). 온라인에서 네 명의 입력을 서버가 모으는 부분은 미구현.
3. 성공 → 셔터 개방 → 클리어 컷씬(기존 8절).

## 3. 스토리 연결
- **씬 4 (완료, `Camp.unity` 끝)**: 어둠 속 첫 소통 시도 → 미션 안내 → Story1. 미션: ① 전원 복구 ② 침수 저지.
- 퍼즐 사이 연결: 각 퍼즐 성공 시 짧은 대사(도윤의 속마음 1~2줄)만. 컷씬은 넣지 않는다.
- 도윤의 변화: 처음엔 "내가 이끌어야" → 퍼즐 2에서 자기 신호가 못 전달돼 감전 → 퍼즐 4에서 마리아의 번역에 의지 → 클리어 컷씬의 깨달음.

## 4. 구현 순서 (제안)
1. 퍼즐 1 (퓨즈 복구) — 역할별 화면·신호·검증·테스트(봇 포함)
2. 퍼즐 2 (젖은 바닥) — 실시간 구간
3. 퍼즐 4 (물길)
4. 퍼즐 5 (최종 동시 입력)
5. 퍼즐 3 (유물 보관실) — 일정이 되면

각 퍼즐은 `PuzzleDef`(데이터) + 서버 검증 + 역할별 뷰로 나눠 서버 권한(GameLogic) 구조에 얹는다.

## 멀티 동기화 (구현됨 · 실제 2인 이상 접속은 미검증)
- 서버(호스트)는 판정하지 않고 `S1` 명령을 보낸 사람 슬롯을 붙여 모두에게 중계한다(`GameLogic` case "S1" → `Story1Net`). 클라는 `Story1Net` 이벤트로 반영.
- 시드: 방장 clientId + 게임 시작 시각 + 퍼즐 번호 → 모든 PC 가 같은 퍼즐. 전시실 스파크 박자는 서버 클록으로 맞춘다.
- Clear: 한 명이 퍼즐을 풀면 전원 복구·패널 닫힘·클리어 표시가 모두에게 반영. Say: 조작자의 진행 한 줄이 다른 역할 패널 하단에 뜬다.
- 최종 퍼즐: 라운드·마지막 시작·각자의 밟기를 중계, 판정은 조작자 PC 가 하고 결과를 모두에게 알린다.
- Pos: 다른 사람의 월드 위치(동료 캐릭터로 표시). 신호 카드: 채팅 없이 숫자·방향·색·예/아니/여기 14장으로만 소통(아래 띠, 오른쪽에 최근 신호).
- 알려진 한계: 조작자가 봇이면 퍼즐을 대신 풀지 못함, 네트워크 지연 보정 없음(밟기 ±0.35초), 접속 끊김 복구 없음.
